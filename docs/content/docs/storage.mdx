---
title: Storage
description: Manage data uploads and run artifacts.
---

Tahuna provides unified cloud storage for your training data and run-produced artifacts. All files are stored in Cloudflare R2 and accessible from the CLI.

## Data uploads

Upload files that your runs need as input:

```bash
tahuna data upload ./my_dataset.json
```

Upload multiple files at once:

```bash
tahuna data upload ./data/*.parquet
```

Uploaded data appears in cloud storage and can be listed via the CLI.

### Renaming data

Data files can be renamed via the CLI.

## Run artifacts

When a run writes to its output directory, those files are automatically collected and stored as artifacts.

Artifacts are read-only and cannot be renamed. They are linked to the run that produced them.


## Downloading files

From the CLI:

```bash
tahuna data download <file-key> -o ./local_path
```

From the CLI, use the download command.

## Storage limits

Storage quotas depend on your plan. Contact support if you need more capacity.
