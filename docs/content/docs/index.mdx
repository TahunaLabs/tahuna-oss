Tahuna runs Python training and inference workloads on managed cloud GPUs while keeping your code, dependencies, and project layout under your control.

You bring a local ML project. Tahuna syncs it into reproducible snapshots, provisions compute, installs dependencies, runs training or serving commands, streams logs and metrics, and stores artifacts outside the runtime machine.

## Start here

Install the CLI, log in, initialize a project, then launch a run:

```bash
curl -fsSL https://tahuna.app/install.sh | bash
tahuna login
tahuna init .
tahuna train
```

Before your first paid launch, add Tahuna credits in the dashboard billing view. See [Installation](/installation) and [Quickstart](/quickstart) for the full first-run path.

- [Environments](/environments) define the project runtime, GPU type/count, volume size, commands, and dependency groups.
- [Syncing](/syncing) records code and data as pinned manifests and uploads only missing file content.
- [Storage](/storage) holds data, run artifacts, and serve model snapshots outside ephemeral compute.
