Tahuna is a training orchestration platform for teams that want full control over their training code without taking on the infrastructure work around it. You keep your Python training loop. Tahuna handles code and data sync, dependency installation, run execution, metrics capture, and artifact persistence, while launches run against your own RunPod account via a user-provided API key.

## Why Tahuna exists

Most ML training workflows still force a bad tradeoff. You can rent raw GPU compute and manage the whole stack yourself, or you can use a managed fine-tuning API and give up control over the training loop. Tahuna sits between those two options. It is the control plane between your local project and cloud GPUs, so you can run custom training and post-training workloads without SSH, Dockerfiles, or cluster setup.

## What Tahuna does - A gentle control plane

Tahuna turns a local project into a reproducible remote run:

- You define an environment for your project.
- Tahuna syncs your code and data into pinned snapshots.
- Tahuna provisions compute, materializes the workspace, and executes your entrypoint.
- Logs, metrics, and output artifacts are captured automatically.

### Ephemeral compute 

Tahuna's runtime compute is ephemeral: runs execute on temporary RunPod pods rather than long-lived machines, and persistent state is reconstructed from pinned snapshots and stored outside the pod. Transport to Tahuna services uses encrypted connections, and your saved provider credentials are encrypted at rest.

## How syncing works

Tahuna syncs code and data incrementally rather than uploading a fresh tarball for every run. It records ordered manifests, uploads only missing content, and pins each run to exact code and data snapshots.

See [Syncing](/syncing) for the full model.

**That makes Tahuna a good fit for researchers, agent builders, and small teams who need custom workflows but do not want to spend their time on GPU operations.**

## Key Concepts

- **Environments** - Isolated compute configurations that define the framework, GPU type, GPU count, and volume size for a project.
- **Runs** - A single remote execution of your code in a Tahuna-managed environment, with logs, metrics, and artifacts captured as the run progresses.
- **Storage** - The object storage layer that holds uploaded data, pinned manifests, and run-produced artifacts.

## Quick Start

```bash
curl -fsSL https://raw.githubusercontent.com/Pazuzzu/tahuna/main/scripts/install-tahuna.sh | bash
tahuna login
tahuna init .
```

Before your first launch, add your RunPod API key in the Tahuna dashboard so Tahuna can provision pods on your behalf:

1. Open the [Tahuna dashboard](/dashboard)
2. Go to Settings / Providers
3. Save your RunPod API key

Then you can launch runs:

```bash
tahuna train
```

See the [Installation](/installation) and [Quickstart](/quickstart) guides for the full setup and first-run workflow.
