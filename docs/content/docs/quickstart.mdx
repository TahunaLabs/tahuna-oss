This guide walks you through the normal Tahuna flow: initialize the project, complete the interactive setup, and start a training run.

## 1. Initialize your project

Navigate to your ML project directory and run:

```bash
tahuna init .
```

This initializes the project locally, walks you through the configuration interactively, and writes `.tahuna/tahuna.toml`. It also scaffolds the project files Tahuna needs, including `pyproject.toml`, `uv.lock`, and `train.py` when they do not already exist.

## 2. Review the configuration

Tahuna keeps local project bindings in `.tahuna/tahuna.toml`:

```toml
[project]
entrypoint = "train.py"
data_dir = "data"
output_dir = "outputs"
python_project_file = "pyproject.toml"
uv_lock_file = "uv.lock"

[environment]
framework = "pt"
python_version = "3.11"
```

You can also review the scaffolded project files directly, especially `train.py` for your entrypoint and `pyproject.toml` for your runtime dependencies.

## 3. Start training

Launch a training run:

```bash
tahuna train
```

Tahuna will:

1. Provision a GPU pod matching your environment spec
2. Sync your code to the pod
3. Execute your training script
4. Stream logs and metrics in real-time
5. Collect output artifacts when the run completes

## 4. Monitor from the dashboard

Open the [Tahuna dashboard](/dashboard) to see your run in the Runs view. Click on a run to see live logs, metrics charts, diagnostics, and output artifacts.
