This guide walks you through creating an environment, uploading data, and launching your first run.

## 1. Initialize your project

Navigate to your ML project directory and run:

```bash
tahuna init .
```

This creates a `tahuna.toml` configuration file in your project root. It defines the environment spec — framework, GPU type, GPU count, and volume size.

## 2. Review the configuration

Open `tahuna.toml` to inspect and customize your environment:

```toml
[environment]
name = "my-project"
framework = "pytorch"
version = "2.4"
gpu_type = "A100"
gpu_count = 1
volume_gb = 50
```

Adjust these values to match your workload requirements.

## 3. Upload training data

If your run needs input data, upload it:

```bash
tahuna data upload ./training_data.json
```

You can upload multiple files. They will appear in the Storage view on the dashboard and can be bound to your environment.

## 4. Launch a run

Start a run in your environment:

```bash
tahuna run
```

Tahuna will:

1. Provision a GPU pod matching your environment spec
2. Sync your code to the pod
3. Execute your training script
4. Stream logs and metrics in real-time
5. Collect output artifacts when the run completes

## 5. Monitor from the dashboard

Open the [Tahuna dashboard](/dashboard) to see your run in the Runs view. Click on a run to see live logs, metrics charts, diagnostics, and output artifacts.
