This guide walks you through the normal Tahuna flow: initialize the project, complete the interactive setup, add Tahuna credits, and start a managed training run.

## 1. Initialize your project

Navigate to your ML project directory and run:

```bash
tahuna init .
```

This initializes the project locally, walks you through the configuration interactively, writes root `tahuna.toml`, and stores link/cache state under `.tahuna/`. It also scaffolds the project files Tahuna needs, including `pyproject.toml`, `uv.lock`, `train.py`, and optionally `inference.py` when they do not already exist.

## 2. Review the configuration

Tahuna keeps local project bindings in root `tahuna.toml`:

```toml
# Generated from local Tahuna project state.
[project]
data_dir = "data"
output_dir = "outputs"

[environment]
framework = "pt"
version = "2.10.0-cu128"
python_version = "3.11"
gpu_type = "L4"
gpu_count = 1
volume_gb = 10

[train]
command = ["uv", "run", "--active", "--no-sync", "python", "-u", "train.py"]
dependency_group = "train"
output_model_path = "outputs/model"
```

You can also review the scaffolded project files directly, especially `train.py` for the training command and `pyproject.toml` / `uv.lock` for runtime dependencies.

## 3. Add Tahuna credits

Tahuna Cloud uses managed billing by default. Before your first paid launch:

1. Open the [Tahuna dashboard](/dashboard)
2. Go to Billing
3. Add credits with Stripe Checkout

You do not need to configure a provider API key for the managed cloud path.

## 4. Start training

Launch a training run:

```bash
tahuna train
```

Tahuna will:

1. Provision a GPU pod matching your environment spec
2. Sync your code to the pod
3. Execute your training script
4. Stream logs and metrics in real-time
5. Collect output artifacts when the run completes

If the estimated run cost exceeds your Tahuna balance, the launch will ask you to add credits first.

## 5. Monitor from the dashboard

Open the [Tahuna dashboard](/dashboard) to see your run in the Runs view. Click on a run to see live logs, metrics charts, diagnostics, and output artifacts.
