## Installation

```bash
curl -fsSL https://tahuna.app/install.sh | bash
```

For manual tarball installation and version pinning, see [Installation](/installation).

## Authentication

### `tahuna login`

Authenticate with your Tahuna account. Opens a browser window for OAuth.

```bash
tahuna login
```

### `tahuna version`

Print the installed CLI version.

```bash
tahuna version
```

## Environments

### `tahuna init`

Initialize an environment in the current directory. Writes local project state to `.tahuna/tahuna.toml` and scaffolds missing project files such as `pyproject.toml`, `uv.lock`, and `train.py`.

```bash
tahuna init .
```

### `tahuna env list`

List all environments in your workspace.

```bash
tahuna env list
```

### `tahuna env rm`

Delete an environment and all its associated runs, logs, and artifacts.

```bash
tahuna env rm <environment-id>
```

## Runs

### `tahuna train`

Launch training in the current environment. Uses managed Tahuna billing by default.

```bash
tahuna train
```

### `tahuna run list`

List runs in your workspace.

```bash
tahuna run list
tahuna run list --verbose
```

### `tahuna run show`

Inspect a specific run.

```bash
tahuna run show <run-id>
```

### `tahuna run cancel`

Cancel a running or queued run.

```bash
tahuna run cancel <run-id>
```

### `tahuna run logs`

Stream logs from a run.

```bash
tahuna run logs <run-id>
tahuna run logs <run-id> --follow
```

### `tahuna run watch`

Watch a run's lifecycle status.

```bash
tahuna run watch <run-id-or-name>
tahuna run watch <run-id-or-name> --interval 5
```

## Research

### `tahuna research run`

Create or resume a local Auto-Research session. New sessions launch and score a baseline run. Resume calls validate one candidate patch, launch one trial, score it, and accept, reject, or mark it inconclusive.

```bash
tahuna research run \
  --program program.md \
  --metric final:eval_loss \
  --minimize \
  --max-trials 5 \
  --max-spend-usd 5 \
  --max-trial-minutes 30 \
  --editable train.py

tahuna research run --resume <session-id>
tahuna research run --resume <session-id> --trial-title "add 5% warmup"
```

See [Auto-Research](/auto-research) for the full workflow, budget model, and session state contract.

### `tahuna research graph`

Render a local SVG progress graph from `.tahuna/research/<session-id>.json`.

```bash
tahuna research graph <session-id>
tahuna research graph <session-id> --output .tahuna/research/<session-id>/progress.svg
```

When `--output` is omitted, the default path is `.tahuna/research/<session-id>/progress.svg`. The SVG shows the baseline, accepted trials, rejected trials, inconclusive trials, and running best line for the session metric.

When the CLI is authenticated, `tahuna research run` also best-effort syncs compact session metadata to the backend for the Dashboard Hillclimb view. The local session JSON remains the resume source of truth.

## Data

### `tahuna data list`

List data items available in your workspace.

```bash
tahuna data list
tahuna data list --verbose
```

### `tahuna data show`

Inspect a specific data item.

```bash
tahuna data show <data-id>
```

### `tahuna env data bind`

Bind a data file to an environment. Bound data is mounted when runs start.

```bash
tahuna env data bind <environment-id> <data-id>
```

### `tahuna env data unbind`

Remove a data binding from an environment.

```bash
tahuna env data unbind <environment-id> <data-id>
```

## Notes

`--help` is available on the top-level command and command groups. `--verbose` is supported on specific subcommands such as `tahuna run list`, `tahuna run show`, `tahuna run logs`, `tahuna data list`, and `tahuna data show`.
