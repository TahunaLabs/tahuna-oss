## Installation

```bash
brew tap Pazuzzu/tahuna
brew install tahuna
```

## Authentication

### `tahuna login`

Authenticate with your Tahuna account. Opens a browser window for OAuth.

```bash
tahuna login
```

### `tahuna logout`

Clear stored credentials.

```bash
tahuna logout
```

## Environments

### `tahuna init`

Initialize an environment in the current directory. Writes local project state to `.tahuna/project.yaml` and scaffolds missing project files such as `config.yaml`, `pyproject.toml`, `uv.lock`, and `train.py`.

```bash
tahuna init .
```

### `tahuna env list`

List all environments in your workspace.

```bash
tahuna env list
```

### `tahuna env delete`

Delete an environment and all its associated runs, logs, and artifacts.

```bash
tahuna env delete <environment-id>
```

## Runs

### `tahuna train`

Launch training in the current environment.

```bash
tahuna train
```

### `tahuna run list`

List runs in your workspace.

```bash
tahuna run list
tahuna run list --verbose
```

### `tahuna run show`

Inspect a specific run.

```bash
tahuna run show <run-id>
```

### `tahuna run cancel`

Cancel a running or queued run.

```bash
tahuna run cancel <run-id>
```

### `tahuna run logs`

Stream logs from a run.

```bash
tahuna run logs <run-id>
tahuna run logs <run-id> --follow
```

## Data

### `tahuna data list`

List data items available in your workspace.

```bash
tahuna data list
tahuna data list --verbose
```

### `tahuna data show`

Inspect a specific data item.

```bash
tahuna data show <data-id>
```

### `tahuna env data bind`

Bind a data file to an environment. Bound data is mounted when runs start.

```bash
tahuna env data bind <environment-id> <data-id>
```

### `tahuna env data unbind`

Remove a data binding from an environment.

```bash
tahuna env data unbind <environment-id> <data-id>
```

## Global Options

| Flag | Description |
| --- | --- |
| `--version` | Print the CLI version |
| `--help` | Show help for any command |
| `--verbose` | Enable verbose output |
