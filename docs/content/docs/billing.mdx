---
title: Billing
description: How Tahuna credits and managed compute billing work.
---

Tahuna Cloud uses managed billing. You add Tahuna credits with Stripe Checkout, launch runs and serves, and Tahuna debits credits for hosted compute and storage usage.

You do not need a separate provider account or provider API key. Tahuna owns the provider credentials, pays for hosted compute, and treats provider-side failures as Tahuna operational issues.

## Credits

- New accounts start with `$0` in Tahuna credits.
- `$1 paid = $1 Tahuna credit`
- Fixed top-ups: `$10`, `$25`, `$100`
- Custom top-ups are available within configured bounds
- Open or cancelled Checkout sessions are not payments and do not appear in payment history

Payment history shows fulfilled Stripe Checkout payments. Ledger history shows balance-affecting events such as credit grants, compute charges, settlement refunds, and storage charges.

## Compute charges

Before a run or serve launches, Tahuna checks that your balance can cover the configured launch estimate. If your balance is too low, the launch fails before provisioning and asks you to add credits.

While compute is active, Tahuna accrues charges from the GPU type, GPU count, volume size, and runtime duration. When a run or serve reaches a terminal state, Tahuna reconciles the final compute charge against the actual runtime duration.

## Storage charges

Tahuna charges storage when stored data grows. Zero or negative size deltas are not charged.

## Not Included Yet

- Stripe Billing Portal
- Saved payment method management
- Auto top-up
- Refund, dispute, or chargeback automation
- In-app invoice or receipt export
- Payment reconciliation reports
