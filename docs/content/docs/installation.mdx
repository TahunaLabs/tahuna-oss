## Requirements

- macOS (`amd64` or `arm64`)
- Linux (`amd64`)
- WSL on Windows (`amd64`)
- Python 3.10+ (for ML frameworks)
- A running self-hosted Tahuna deployment

## Install with the installer script

Until this repository publishes its own releases, clone `TahunaLabs/tahuna-oss` and run `make install-cli-dev`, then use `tahuna-dev` in place of `tahuna`. Once an OSS release is available, the installer below downloads only from this repository:

```bash
curl -fsSL https://raw.githubusercontent.com/TahunaLabs/tahuna-oss/main/scripts/install-tahuna.sh | bash
```

This command resolves the `stable` channel from `releases/channels.conf`.

To install the rolling nightly channel (published manually):

```bash
curl -fsSL https://raw.githubusercontent.com/TahunaLabs/tahuna-oss/main/scripts/install-tahuna.sh | bash -s -- --channel nightly
```

Verify the installation:

```bash
tahuna version
```

## Manual install (without `curl | bash`)

If you prefer to download and unpack manually, pick the artifact that matches your OS and CPU:

- `tahuna_darwin_amd64.tar.gz`
- `tahuna_darwin_arm64.tar.gz`
- `tahuna_linux_amd64.tar.gz`

Example:

```bash
VERSION=v0.1.0
OS=darwin
ARCH=arm64
curl -fsSL -o tahuna.tar.gz "https://github.com/TahunaLabs/tahuna-oss/releases/download/${VERSION}/tahuna_${OS}_${ARCH}.tar.gz"
tar -xzf tahuna.tar.gz
install -m 0755 tahuna ~/.local/bin/tahuna
```

Release checksums are published in `checksums.txt` for each release tag.

## Authenticate

Log in to your Tahuna account:

```bash
tahuna login
```

This opens a browser window for authentication. Once complete, your credentials are stored locally and all subsequent commands are authenticated.

## Compute configuration

Follow the [self-hosting setup](https://github.com/TahunaLabs/tahuna-oss#readme) to configure AWS or RunPod credentials on your deployment. Compute costs are billed to your provider account.

The CLI defaults to `http://localhost:3000`. Set `TAHUNA_API_URL` to your server URL before logging in when using a remote deployment.

## Update

To update to the latest version:

```bash
curl -fsSL https://raw.githubusercontent.com/TahunaLabs/tahuna-oss/main/scripts/install-tahuna.sh | bash
```

To install a specific version:

```bash
curl -fsSL https://raw.githubusercontent.com/TahunaLabs/tahuna-oss/main/scripts/install-tahuna.sh | bash -s -- --version v0.1.0
```

To update on nightly channel:

```bash
curl -fsSL https://raw.githubusercontent.com/TahunaLabs/tahuna-oss/main/scripts/install-tahuna.sh | bash -s -- --channel nightly
```
