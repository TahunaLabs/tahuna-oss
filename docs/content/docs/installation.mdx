## Requirements

- macOS (`amd64` or `arm64`)
- Linux (`amd64`)
- WSL on Windows (`amd64`)
- Python 3.10+ (for ML frameworks)
- A Tahuna account

## Install with the installer script

The recommended way to install the Tahuna CLI:

```bash
curl -fsSL https://raw.githubusercontent.com/Pazuzzu/tahuna/main/scripts/install-tahuna.sh | bash
```

This command resolves the `stable` channel from `releases/channels.conf`.

To install the rolling nightly channel (built from `main`):

```bash
curl -fsSL https://raw.githubusercontent.com/Pazuzzu/tahuna/main/scripts/install-tahuna.sh | bash -s -- --channel nightly
```

Verify the installation:

```bash
tahuna version
```

## Manual install (without `curl | bash`)

If you prefer to download and unpack manually, pick the artifact that matches your OS and CPU:

- `tahuna_darwin_amd64.tar.gz`
- `tahuna_darwin_arm64.tar.gz`
- `tahuna_linux_amd64.tar.gz`

Example:

```bash
VERSION=v0.1.0
OS=darwin
ARCH=arm64
curl -fsSL -o tahuna.tar.gz "https://github.com/Pazuzzu/tahuna-cli/releases/download/${VERSION}/tahuna_${OS}_${ARCH}.tar.gz"
tar -xzf tahuna.tar.gz
install -m 0755 tahuna ~/.local/bin/tahuna
```

Release checksums are published in `checksums.txt` for each release tag.

## Authenticate

Log in to your Tahuna account:

```bash
tahuna login
```

This opens a browser window for authentication. Once complete, your credentials are stored locally and all subsequent commands are authenticated.

## Configure your RunPod key

Tahuna now launches compute using your own RunPod account. Before you start your first run, add a RunPod API key in the Tahuna dashboard:

1. Open the [Tahuna dashboard](/dashboard)
2. Go to Settings / Providers
3. Save your RunPod API key

Tahuna stores the credential encrypted at rest and uses it only for new RunPod launches.

## Update

To update to the latest version:

```bash
curl -fsSL https://raw.githubusercontent.com/Pazuzzu/tahuna/main/scripts/install-tahuna.sh | bash
```

To install a specific version:

```bash
curl -fsSL https://raw.githubusercontent.com/Pazuzzu/tahuna/main/scripts/install-tahuna.sh | bash -s -- --version v0.1.0
```

To update on nightly channel:

```bash
curl -fsSL https://raw.githubusercontent.com/Pazuzzu/tahuna/main/scripts/install-tahuna.sh | bash -s -- --channel nightly
```
