## Requirements

- macOS, Linux, or WSL on Windows
- Python 3.10+ (for ML frameworks)
- A Tahuna account

## Install via Homebrew

The recommended way to install the Tahuna CLI:

```bash
brew tap Pazuzzu/tahuna
brew install tahuna
```

If you prefer a single command, you can install directly from the tap:

```bash
brew install Pazuzzu/tahuna/tahuna
```

Verify the installation:

```bash
tahuna version
```

## Authenticate

Log in to your Tahuna account:

```bash
tahuna login
```

This opens a browser window for authentication. Once complete, your credentials are stored locally and all subsequent commands are authenticated.

## Configure your RunPod key

Tahuna now launches compute using your own RunPod account. Before you start your first run, add a RunPod API key in the Tahuna dashboard:

1. Open the [Tahuna dashboard](/dashboard)
2. Go to Settings / Providers
3. Save your RunPod API key

Tahuna stores the credential encrypted at rest and uses it only for new RunPod launches.

## Update

To update to the latest version:

```bash
brew update
brew upgrade tahuna
```

## Next Steps

Once installed, head to the [Quickstart](/docs/quickstart) guide to create your first environment and launch a run with your configured RunPod key.
